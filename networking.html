Core Knowledge

CCNA Topic Areas

The technical domains covered by the CCNA 200-301 exam and applied in real environments.

IP Routing

Static and dynamic routing protocols including OSPF, EIGRP, and RIP. Inter-VLAN routing and route redistribution.

Switching & VLANs

VLAN configuration, 802.1Q trunking, STP (Spanning Tree Protocol), EtherChannel, and Layer 2 security.

Subnetting & IPv6

CIDR notation, VLSM, IPv4/IPv6 addressing, DHCP, NAT/PAT, and address planning for enterprise networks.

Network Security

ACLs (standard and extended), port security, AAA framework, VPNs, and securing network device access.

Wireless Networking

WLAN architecture, 802.11 standards, WLC configuration, RF fundamentals, and wireless security (WPA2/WPA3).

Network Automation

Introduction to SDN, network programmability, REST APIs, Python for automation, and Cisco DNA Center basics.

Infrastructure Services

DNS, DHCP, NTP, SNMP, Syslog, and CDP/LLDP for device discovery and network management.

WAN Technologies

Point-to-Point, MPLS, SD-WAN concepts, Internet connectivity options, and broadband technologies.

OSI & TCP/IP Model

Deep understanding of all 7 OSI layers, TCP/UDP protocols, encapsulation, and network troubleshooting methodology.
